## How I work

1. Attempt the problem alone first (20 to 30 minutes) before any hint or video.
2. Write the brute force and its complexity, then look for what is wasted.
3. Code it, trace it by hand, then submit.
4. Re-solve it the next day from a blank editor.
5. Write down the pattern name and the complexity.
